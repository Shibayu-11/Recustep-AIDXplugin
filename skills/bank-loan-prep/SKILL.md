# 銀行融資準備スキル

## いつ使うか

- 「銀行から借りたい」「融資の相談を受けたい」と言われたとき
- 運転資金・設備資金の調達が必要なとき
- 借り換え・追加融資の検討時

## 銀行が見るポイント

### 融資審査の5つの視点

| 視点 | 銀行が確認すること | AIDXが支援できること |
|------|-------------------|-------------------|
| **収益性** | 売上・利益のトレンド、営業利益率 | PL分析、3期比較レポート |
| **安全性** | 自己資本比率、流動比率、債務超過でないか | BS分析、財務健全性スコア |
| **返済能力** | 返済原資（営業CF + 減価償却費）、DSCR | CF分析、返済シミュレーション |
| **資金使途** | 何に使うか、妥当な金額か | 資金使途説明書のたたき台 |
| **経営者** | 経営計画の有無、業界知識、返済意思 | 事業計画書の作成支援 |

### DSCR（Debt Service Coverage Ratio）
```
DSCR = (営業利益 + 減価償却費) / (借入金元本返済額 + 支払利息)

1.2以上: 安全（銀行が安心する水準）
1.0〜1.2: ギリギリ（追加担保や保証を求められる可能性）
1.0未満: 危険（返済原資が不足）
```

## ワークフロー

### Phase 1: 現状分析

既存の財務データ（`data/financial/`）を基に：
1. 直近3期のPL/BS/CFを分析
2. 主要財務指標を算出
3. 銀行目線での評価（良い点・懸念点）

### Phase 2: 必要書類の作成支援

| 書類 | 内容 | AIDXの出力 |
|------|------|-----------|
| **事業計画書** | 事業概要、市場分析、成長戦略、収支計画 | Markdownドラフト |
| **資金繰り表** | 今後12ヶ月の資金繰り予測 | Excel/CSVテンプレート |
| **借入申込概要** | 借入希望額、期間、返済方法、資金使途 | フォーマット記入サポート |
| **決算書の補足説明** | 異常値・一時的費用の説明 | 説明文のドラフト |

### Phase 3: 事業計画書テンプレート

```markdown
# 事業計画書

## 1. 企業概要
- 会社名、所在地、設立年月、代表者
- 事業内容、主要取引先、従業員数

## 2. 事業の現状
- 直近3期の業績推移（売上、営業利益、経常利益）
- 主力事業の強み・市場ポジション
- 現在の課題

## 3. 今後の事業計画
- 成長戦略（3年間）
- 売上・利益の計画値（月次or年次）
- 投資計画と期待効果

## 4. 資金計画
- 必要資金: ○○万円
- 資金使途: [設備投資/運転資金/借り換え]の内訳
- 返済計画: 期間○年、月額○万円、返済原資の根拠

## 5. リスクと対策
- 想定されるリスクと対応策

## 添付資料
- 直近3期分の決算書
- 資金繰り表（12ヶ月分）
- 設備投資の場合: 見積書
```

### Phase 4: 返済シミュレーション

```
借入額: 3,000万円
金利: 2.0%（変動）
期間: 7年（84ヶ月）
返済方法: 元金均等返済

月額返済額（元金）: 357,143円
初月利息: 50,000円
初月合計: 407,143円
総返済額: 32,100,000円
```

### Phase 5: 面談準備

銀行担当者との面談で聞かれる質問と回答案：
1. 「なぜ今このタイミングで融資が必要なのか？」
2. 「返済原資は何か？」
3. 「担保・保証人は？」
4. 「競合と比べた御社の強みは？」
5. 「最悪のケースでも返済できる根拠は？」

## 注意事項

- 事業計画は「控えめで現実的な数字」を推奨。過大な計画は信頼を損なう
- 銀行ごとに求める書類が異なる。事前に取引銀行に確認すること
- 日本政策金融公庫は比較的借りやすい。創業融資はまず公庫を検討
- 信用保証協会付き融資は保証料が別途発生（0.5〜2.0%程度）
