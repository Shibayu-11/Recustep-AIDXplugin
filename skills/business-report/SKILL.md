# ビジネスレポート作成スキル

## いつ使うか

- 経営者向けの定期報告書を作成するとき
- 分析結果をまとめてレポートにするとき
- 社外提出用の報告書・提案書を作成するとき

## レポートの種類と構成

### 月次経営レポート
1. **エグゼクティブサマリー**（1段落で結論）
2. **KPIダッシュボード**（主要指標の表）
3. **売上分析**（セグメント別、前月比、前年比）
4. **費用分析**（主要費目の増減）
5. **トピックス**（特記事項、リスク、機会）
6. **来月の見通し**
7. **推奨アクション**

### 調査レポート
1. **目的**
2. **調査方法**
3. **結果**（データ・ファクト）
4. **分析**（解釈・示唆）
5. **結論と推奨**

### 提案書
1. **エグゼクティブサマリー**
2. **背景・課題**
3. **提案内容**
4. **期待効果**（定量的に）
5. **スケジュール・体制**
6. **予算**
7. **リスクと対策**

## 文章の原則

### 結論ファースト
```
× 調査の結果、A事業の売上が前年比15%減少していることが判明しました。
  原因としては競合B社の価格攻勢が考えられます。
  対策として、差別化戦略の強化を提案します。

○ A事業は差別化戦略の強化が急務です。
  売上が前年比15%減少しており、主因は競合B社の価格攻勢です。
  具体的には、以下3つの施策を提案します。
```

### 数値を使う
```
× 売上は大幅に増加しました。
○ 売上は前月比+12%（5,200万円）に増加しました。
```

### 具体的なアクションを提示
```
× 改善が必要です。
○ 来月末までに以下3点を実施してください:
  1. 売掛金60日超の取引先5社に督促連絡
  2. 新規取引先の与信基準を売上高1億円以上に引き上げ
  3. 月次の債権回収会議を第1月曜に設定
```

## 品質基準

- 1ページ目（またはエグゼクティブサマリー）だけで判断できる構成にする
- グラフ・表を効果的に使い、文章の壁を作らない
- 根拠のない主張をしない（データまたは事実を引用）
- 「良い/悪い」は必ず基準を明示（前年比、予算比、業界平均等）
