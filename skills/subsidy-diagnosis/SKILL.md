# 補助金・助成金診断スキル

## いつ使うか

- 「うちが使える補助金ある？」と聞かれたとき
- 設備投資・DX推進・採用・研修等の計画があるとき
- 新規クライアント導入時の初期提案として

## ワークフロー

### Step 1: 企業プロファイル収集

以下を必ず確認：

1. **業種**: 製造業/サービス業/小売業/IT等
2. **従業員数**: 個人事業主/小規模（20人以下）/中小（300人以下）/中堅
3. **資本金**: 中小企業基本法の定義に該当するか
4. **所在地**: 都道府県（自治体独自の補助金に影響）
5. **直近の計画**: 設備投資、IT導入、採用、研修、新規事業等
6. **過去の利用実績**: 同一補助金の再申請制限に注意

### Step 2: リアルタイム情報収集

**静的データに頼るな。必ずWeb検索で最新の公募状況を確認すること。**

以下のソースから最新情報を取得：

#### 公式ソース（必ず確認）
```bash
# 中小企業庁の補助金ページ
curl -s "https://r.jina.ai/https://www.chusho.meti.go.jp/koukai/koubo/"

# J-Net21（中小企業向け補助金・助成金情報）
curl -s "https://r.jina.ai/https://j-net21.smrj.go.jp/snavi/support/"

# ミラサポplus（中小企業向け補助金・給付金）
curl -s "https://r.jina.ai/https://mirasapo-plus.go.jp/subsidy/"
```

#### 補助金検索（キーワード）
```bash
# Google検索で最新の公募情報
curl -s "https://r.jina.ai/https://www.google.com/search?q={業種}+補助金+公募中+2026&hl=ja"

# 都道府県別
curl -s "https://r.jina.ai/https://www.google.com/search?q={都道府県}+中小企業+補助金+2026&hl=ja"
```

### Step 3: 主要補助金のマッチング

以下は代表的な制度の概要。**必ずStep 2のWeb検索で最新の公募状況・金額・要件を確認してから提示すること。**

#### 経済産業省系

| 補助金 | 対象 | 概要 |
|--------|------|------|
| IT導入補助金 | 中小企業のIT化 | ITツール導入費用を補助 |
| ものづくり補助金 | 製造業等の設備投資 | 革新的サービス・試作品開発 |
| 事業再構築補助金 | 事業転換・新分野進出 | 思い切った事業再構築を支援 |
| 小規模事業者持続化補助金 | 小規模事業者の販路開拓 | 販路開拓の取り組みを支援 |
| 省力化投資補助金 | 人手不足対策 | 省力化製品の導入を支援 |

#### 厚生労働省系

| 助成金 | 対象 | 概要 |
|--------|------|------|
| キャリアアップ助成金 | 非正規→正社員化 | 有期→正社員転換を助成 |
| 人材開発支援助成金 | 社員研修 | OFF-JT/OJT費用を助成 |
| 両立支援等助成金 | 育休取得支援 | 育休取得促進措置を助成 |
| トライアル雇用助成金 | 未経験者の試用雇用 | ハローワーク経由の雇用 |
| 65歳超雇用推進助成金 | 高齢者雇用 | 定年延長・継続雇用制度 |

#### 自治体系

都道府県・市区町村の独自補助金はWeb検索で取得すること。
「{都道府県} 中小企業 補助金 2026」で検索。

### Step 4: 診断結果の出力

```markdown
## 補助金・助成金 診断結果

**診断日:** YYYY/MM/DD
**企業概要:** {業種} / {従業員数}名 / {所在地}

---

### 該当する可能性が高い制度

#### 1. {制度名}【公募中 / 次回公募待ち / 通年】
- **補助額:** {最新の上限額}（補助率: {X%}）
- **公募期間:** {現在の公募期間 or 次回公募の見込み}
- **御社の該当理由:** {具体的に}
- **申請の難易度:** 高/中/低
- **準備期間の目安:** {X週間}
- **公式URL:** {取得したURL}

#### 2. {制度名}
- ...

---

### 参考情報
- {その他の候補}

### 注意事項
- 上記は{診断日}時点の情報です。公募状況は随時変更されます
- 正確な要件・申請方法は公式サイトまたは商工会議所でご確認ください
- 申請書類の作成支援が必要な場合はお申し付けください
```

### Step 5: 申請準備サポート

マッチした制度に対して：
1. **必要書類チェックリスト**を作成
2. **事業計画書のたたき台**を生成（ものづくり補助金等）
3. **申請スケジュール**を逆算で作成
4. **認定支援機関が必要な場合**はその旨を明記

### Step 6: GBrainに記録

- クライアントページに「診断済み補助金」として記録
- 公募期限をリマインダーに設定
- 申請結果が出たら採択/不採択を更新

## 絶対に守るルール

1. **Web検索で最新情報を確認せずにハードコードされたデータだけで回答するな**
2. **公募が終了している制度を「使えます」と言うな**
3. **金額・補助率は最新の公募要領から引用しろ。古い情報で回答するな**
4. **「概算」「目安」と必ず付けろ。確定情報のように見せるな**
5. **申請の可否を断言するな。「該当する可能性が高い」と表現しろ**

## 営業での活用ポイント

初回ヒアリングで補助金診断を出すと：
- 「こんな制度があるの知らなかった」→ 信頼獲得
- 「AIDX導入費用を補助金で賄えるかも」→ 導入ハードルが下がる
- IT導入補助金はAIDX自体の導入費用にも該当する可能性あり
