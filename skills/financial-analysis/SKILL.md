# 財務分析スキル

## いつ使うか

- 経営者が「売上を分析して」「今月の財務状況は？」と聞いたとき
- `data/financial/` にExcel/CSVが配置されたとき
- KPIの予実比較、トレンド分析が必要なとき

## ワークフロー

### Step 1: データ確認
1. `data/financial/` 内のファイルを確認
2. ファイル形式（Excel/CSV）とカラム構成を把握
3. 期間（月次/四半期/年次）を特定

### Step 2: 基本分析
1. **PL分析**: 売上高 → 売上原価 → 粗利益 → 販管費 → 営業利益 の構造を把握
2. **BS分析**: 流動資産/固定資産、流動負債/固定負債、自己資本比率を算出
3. **CF分析**: 営業CF、投資CF、財務CF の内訳と傾向を把握

### Step 3: KPIモニタリング
| KPI | 計算式 | 健全基準 |
|-----|--------|---------|
| 売上高成長率 | (当期売上 - 前期売上) / 前期売上 | 業界平均以上 |
| 粗利益率 | 粗利益 / 売上高 | 業界により異なる |
| 営業利益率 | 営業利益 / 売上高 | 5%以上が目安 |
| 自己資本比率 | 自己資本 / 総資産 | 40%以上が安定 |
| 流動比率 | 流動資産 / 流動負債 | 200%以上が安全 |
| 売上債権回転日数 | 売上債権 / (売上高/365) | 短いほど良い |

### Step 4: レポート出力
1. エグゼクティブサマリー（結論を1-2文で）
2. KPIサマリー表（実績・予算・達成率・評価）
3. 詳細分析（良い点・悪い点・トレンド）
4. 推奨アクション（具体的に3-5個）

## 出力例

```
## 📋 要約
売上高は前月比+12%と好調。ただし売上債権回転日数が悪化傾向にあり、資金繰りへの注意が必要。

## 📊 KPI
| 指標 | 実績 | 予算 | 達成率 | 評価 |
|------|------|------|--------|------|
| 売上高 | 5,200万円 | 5,000万円 | 104% | ✅ 良好 |
| 営業利益率 | 15.2% | 14.0% | 109% | ✅ 良好 |
| 売上債権回転日数 | 62日 | 55日 | — | ⚠️ 要注意 |

## ✅ 推奨アクション
1. 売上債権の回収状況を確認し、60日超の未回収先をリスト化
2. 来月の広告費を+10%増額して好調な勢いを維持
3. 新規取引先への与信審査基準を見直し
```

## 注意事項
- 数値には必ず単位を付ける
- 前年比・前月比がある場合は必ず比較する
- 投資助言や税務アドバイスは行わない
