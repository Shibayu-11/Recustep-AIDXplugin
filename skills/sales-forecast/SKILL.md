# 時系列予測スキル（TimesFM連携）

## いつ使うか

- 「来月の売上予測して」→ 過去データから売上を予測
- 「資金繰りの見通し教えて」→ 3-6ヶ月先のキャッシュフロー予測
- 「在庫どれぐらい持てばいい？」→ 需要予測から適正在庫を算出
- 「このペースだとKPIどうなる？」→ トレンド予測

## 前提条件

TimesFMがインストール済みであること。

```bash
pip install timesfm[torch]
```

GPU推奨（CPU実行可能だが遅い）。

## TimesFMとは

Googleが開発した時系列予測の基盤モデル（ICML 2024）。
- 200Mパラメータ
- 最大16,000ポイントのコンテキスト
- ゼロショット予測（追加学習不要）
- 確率的予測（信頼区間付き）

## ワークフロー

### Step 1: データ準備

`data/financial/` から時系列データを取得。

必要なデータ:
- 日次 or 月次の数値データ（売上、来客数、注文数等）
- 最低12ポイント（12ヶ月分 or 12日分）推奨
- 多いほど精度が上がる（理想は24ヶ月以上）

### Step 2: 予測実行

```python
import timesfm
import numpy as np

# モデルロード
tfm = timesfm.TimesFm(
    hparams=timesfm.TimesFmHparams(
        per_core_batch_size=32,
        horizon_len=6,  # 6ヶ月先まで予測
        num_layers=20,
        model_dims=1280,
    ),
    checkpoint=timesfm.TimesFmCheckpoint(
        huggingface_repo_id="google/timesfm-2.0-500m-pytorch"
    ),
)

# 過去データ（例: 月次売上）
historical = [4200, 4500, 5200, 4800, 5100, 5500, 4900, 5300, 5800, 5200, 5600, 6000]

# 予測
forecast = tfm.forecast(
    inputs=[np.array(historical, dtype=np.float32)],
    freq=[0],  # 0=月次
)

# 結果
point_forecast = forecast[0][0]  # ポイント予測
quantiles = forecast[1][0]        # 信頼区間
```

### Step 3: 結果の解釈

```
## 売上予測（今後6ヶ月）

| 月 | 予測値 | 下限（10%） | 上限（90%） | 前年同月 |
|-----|--------|-----------|-----------|---------|
| 7月 | 6,200万 | 5,800万 | 6,600万 | 5,500万 |
| 8月 | 6,400万 | 5,900万 | 6,900万 | 4,900万 |
| ... | ... | ... | ... | ... |

トレンド: 月平均+3.2%の成長。この傾向が続けば年末には月商7,000万円台。
リスク: 8月は季節変動で下振れリスクあり（下限5,900万円）。
```

### Step 4: 財務エージェントとの連携

予測結果を財務エージェントに渡して：
1. 予測売上に基づく損益シミュレーション
2. 資金繰り表の更新（キャッシュポジション予測）
3. 予算との乖離分析

## 予測精度を上げるコツ

| 要素 | 推奨 |
|------|------|
| データ量 | 24ヶ月以上 |
| データ頻度 | 月次が基本。日次ならさらに良い |
| 欠損値 | 補間してから投入 |
| 外れ値 | コロナ等の異常期間はフラグを付ける |
| 季節性 | 12ヶ月以上で自動検出 |

## TimesFMが使えない場合

GPUもTimesFMもない場合は、Claudeの推論ベースで簡易予測する：
- 移動平均法（3ヶ月/6ヶ月/12ヶ月移動平均）
- 前年同月比法
- 線形回帰

精度は落ちるが、何もないよりはマシ。

## 注意事項

- 予測は「このまま行ったらこうなる」であって「必ずこうなる」ではない
- 新規事業・市場変動・法規制変更等の構造変化は予測に反映されない
- 必ず「予測の前提条件」と「予測が外れるリスク」を明記すること
- 経営判断は予測だけでなく、定性的な判断も含めて行うこと
