# 見積書・請求書作成スキル

## いつ使うか

- 「見積書を作って」「請求書を出して」と言われたとき
- インボイス制度（適格請求書）対応の書類が必要なとき

## インボイス制度（適格請求書）必須記載事項

2023年10月以降、以下の記載が法的に必要：

1. **適格請求書発行事業者の氏名または名称** + **登録番号**（T+13桁）
2. **取引年月日**
3. **取引内容**（軽減税率対象の場合はその旨）
4. **税率ごとに区分した対価の額** + **適用税率**
5. **税率ごとに区分した消費税額**
6. **書類の交付を受ける事業者の氏名または名称**

## 見積書フォーマット

```markdown
見積書

見積番号: EST-YYYYMMDD-001
発行日: YYYY年MM月DD日
有効期限: YYYY年MM月DD日

【発行元】
株式会社○○
〒xxx-xxxx ○○県○○市...
TEL: xxx-xxxx-xxxx
登録番号: T1234567890123

【宛先】
△△株式会社 御中

件名: ○○に関するお見積り

| No. | 品名・内容 | 数量 | 単位 | 単価 | 金額 |
|-----|-----------|------|------|------|------|
| 1 | ○○作業 | 1 | 式 | 100,000 | 100,000 |
| 2 | △△費用 | 5 | 日 | 50,000 | 250,000 |

小計: ¥350,000
消費税（10%）: ¥35,000
合計: ¥385,000

備考:
- 上記金額には消費税が含まれています
- 有効期限を過ぎた場合は再見積りとなります
```

## 請求書フォーマット

見積書と同様の構成に加え：
- **請求番号**: INV-YYYYMMDD-001
- **支払期限**: YYYY年MM月DD日
- **振込先口座**: 銀行名、支店名、口座種別、口座番号、口座名義

## HTML出力

`templates/invoice.html` テンプレートを使用（未作成の場合は `templates/base.html` を継承して生成）。

context:
```python
{
    "title": "見積書",
    "doc_number": "EST-20260411-001",
    "date": "2026年4月11日",
    "issuer": { "name": "...", "address": "...", "tel": "...", "registration": "T..." },
    "recipient": "△△株式会社 御中",
    "subject": "○○に関するお見積り",
    "items": [
        {"no": 1, "name": "○○作業", "qty": 1, "unit": "式", "price": 100000, "amount": 100000},
    ],
    "subtotal": 350000,
    "tax_rate": 10,
    "tax": 35000,
    "total": 385000,
    "notes": "有効期限: 2026年5月11日",
}
```

## 注意事項

- 登録番号は必ず確認する（間違いは法的リスク）
- 軽減税率（8%）対象品目がある場合は税率ごとに区分
- 端数処理: 1請求書あたり税率ごとに1回（切り捨て/四捨五入/切り上げは事業者選択）
