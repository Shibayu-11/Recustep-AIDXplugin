# 経営戦略レビュー

## いつ使うか

- 四半期の経営計画レビュー
- 大きな意思決定（新規事業、M&A、大型投資）の前
- 「うちの方向性、これでいいのか？」という問い

## 4つのスコープモード

経営者にまず聞く：「今、どのモードですか？」

| モード | 状態 | やること |
|--------|------|---------|
| **拡大** | 売上好調、資金余裕あり | 新規事業・市場拡大を積極検討 |
| **選択的拡大** | 基盤は安定、一部に賭ける | コア事業を守りつつ、1-2の新施策に集中投資 |
| **維持** | 外部環境が不透明 | 今の事業を磨き込む。防御重視 |
| **縮小** | 資金繰り厳しい、市場縮小 | 不採算を切り、コアに絞る |

## ワークフロー

### Phase 1: 現状把握

以下のデータを確認：
- 直近3ヶ月の売上・利益推移
- キャッシュポジション
- 主要KPIの達成率
- 競合の動き
- 外部環境の変化（法規制、市場トレンド）

### Phase 2: 認知パターンの適用

GStackのCEOレビューから借用した思考パターン：

1. **分類本能** — 課題を「今すぐ」「今期中」「来期以降」に仕分ける
2. **反転思考** — 「これが最悪の結果になるシナリオは？」から逆算する
3. **引き算のフォーカス** — やらないことを決める。やることリストより、やめることリスト
4. **エッジケース妄想** — 「主要顧客が来月解約したら？」「キーパーソンが退職したら？」
5. **信頼の設計** — 顧客・従業員・取引先からの信頼を壊す施策は即却下

### Phase 3: 戦略オプション提示

必ず3つのオプションを出す：

```markdown
## 戦略オプション

### A: [攻めの選択肢]
- 内容: [具体的に]
- 投資額: [概算]
- 期待リターン: [数字で]
- リスク: [最悪のケース]
- 成功確率: [根拠付きで]

### B: [バランスの選択肢]
- ...

### C: [守りの選択肢]
- ...

### 推奨: [A/B/C] — [理由を1文で]
```

### Phase 4: 意思決定サポート

経営者が選択したオプションに対して：
1. **実行計画**を3ヶ月分作成
2. **KPI**を設定（月次チェックポイント）
3. **撤退基準**を明確化（「この数字を下回ったら止める」）
4. **次回レビュー日**を設定

### Phase 5: GBrainに記録

- `org/strategy-YYYYQN.md` に戦略決定を記録
- 関連するクライアント・プロジェクトページにリンク
- 次回レビューのリマインダーを設定

## 鉄則

- **数字なき戦略は戦略ではない** — 全てのオプションに金額・期間・確率を
- **やめる勇気** — 3つのオプションのうち1つは必ず「やめる/縮小する」を含める
- **撤退基準を先に決める** — 始める前に「いつ止めるか」を決めておく
