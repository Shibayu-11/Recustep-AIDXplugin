# 契約書レビュースキル

## いつ使うか

- 経営者が「この契約書をチェックして」と依頼したとき
- `data/contracts/` にPDFが配置されたとき
- NDA、業務委託、売買契約等のレビューが必要なとき

## ワークフロー

### Step 1: 契約書読み込み
1. `data/contracts/` 内のPDFを読み込み
2. 契約種類を特定（NDA/業務委託/売買/賃貸借/ライセンス等）
3. 当事者・契約期間・対象を確認

### Step 2: リスクチェックリスト

#### 必ず確認する条項
| 条項 | チェックポイント | リスクレベル |
|------|-----------------|-------------|
| 契約期間・更新 | 自動更新の有無、解約予告期間 | 中 |
| 報酬・支払条件 | 支払期日、遅延利息、値上げ条項 | 高 |
| 損害賠償 | 賠償上限の有無、間接損害の扱い | 高 |
| 秘密保持 | 秘密情報の定義、期間、例外 | 中 |
| 知的財産 | 成果物の帰属、ライセンス範囲 | 高 |
| 解除・解約 | 解除事由、解約時の精算方法 | 高 |
| 競業避止 | 期間、地域、対象業務の範囲 | 中 |
| 不可抗力 | 定義の範囲、免責の程度 | 低 |
| 準拠法・管轄 | 日本法か外国法か、管轄裁判所 | 中 |

### Step 3: リスク評価
- **高リスク**: 経営に重大な影響を与えうる条項（損害賠償無制限、一方的解除権等）
- **中リスク**: 交渉で修正すべき条項（支払条件、競業避止等）
- **低リスク**: 確認・認識しておくべき条項（不可抗力、準拠法等）

### Step 4: 修正提案
各リスク項目に対して：
1. 現在の条項内容を引用
2. リスクの説明（何が問題か、最悪のケースは何か）
3. 修正案（より有利な文言の提案）

### Step 5: 弁護士確認事項リスト
高リスク項目を中心に、弁護士に確認すべき論点をリスト化

## 出力例

```
## 高リスク — 第8条（損害賠償）
現在の条項: 「甲は乙に対し、本契約に関して生じた一切の損害を賠償する」
問題点: 賠償上限の定めがなく、間接損害・逸失利益も含まれる可能性がある
推奨: 「賠償額の上限は本契約の報酬総額とする」等の上限条項を追加

## 弁護士に確認すべき事項
1. 損害賠償上限の追加交渉が可能か
2. 競業避止条項の期間（2年）が合理的範囲か
3. 知的財産の帰属条項が自社に不利でないか
```

## 免責事項
本レビューは参考情報であり、法的助言ではない。最終判断は必ず弁護士に確認すること。
