# 経営分析フレームワークスキル

## いつ使うか

- 経営者が「SWOT分析をして」「競合分析をお願い」と依頼したとき
- 事業計画の策定・見直しが必要なとき
- 新規事業の検討時

## フレームワーク一覧

### 1. SWOT分析

**目的:** 自社の内部環境（強み・弱み）と外部環境（機会・脅威）を整理する

```
┌──────────────────────┬──────────────────────┐
│    強み (Strengths)  │    弱み (Weaknesses) │
│                        │                        │
│ ・[内部の優位性]        │ ・[内部の課題]          │
│ ・[他社にない資源]      │ ・[不足しているもの]    │
│ ・[顧客から評価される点]│ ・[改善が必要な点]      │
├──────────────────────┼──────────────────────┤
│    機会 (Opportunities)│   脅威 (Threats)    │
│                        │                        │
│ ・[市場の成長]          │ ・[競合の動き]          │
│ ・[規制緩和]            │ ・[技術変化]            │
│ ・[顧客ニーズの変化]    │ ・[経済環境の悪化]      │
└──────────────────────┴──────────────────────┘
```

**クロスSWOT（戦略導出）:**
| | 機会 (O) | 脅威 (T) |
|---|---------|---------|
| **強み (S)** | SO戦略: 強みで機会を活かす | ST戦略: 強みで脅威を回避 |
| **弱み (W)** | WO戦略: 弱みを克服して機会を活かす | WT戦略: 弱みと脅威の影響を最小化 |

### 2. 3C分析

**目的:** 自社・顧客・競合の3つの視点から事業環境を分析する

**Customer（顧客）:**
- ターゲットセグメントは誰か？
- 顧客のニーズ・課題は何か？
- 購買の意思決定プロセスは？
- 顧客の規模・成長性は？

**Competitor（競合）:**
- 主要な競合は誰か？
- 競合のシェア・強み・弱みは？
- 競合の戦略（価格、チャネル、差別化）は？
- 新規参入の脅威は？

**Company（自社）:**
- 自社の強み・独自性は何か？
- リソース（人材、資金、技術）の状況は？
- ブランド・評判は？
- 競合に対する優位性は？

### 3. PEST分析

**目的:** マクロ環境の変化を4つの視点で整理する

| 要因 | 分析項目 |
|------|---------|
| **Political（政治）** | 法規制、税制、補助金、貿易政策、政治的安定性 |
| **Economic（経済）** | GDP成長率、為替、金利、インフレ率、雇用情勢 |
| **Social（社会）** | 人口動態、ライフスタイル変化、消費者意識、働き方改革 |
| **Technological（技術）** | AI/DX、自動化、新技術の普及、R&D動向 |

### 4. ビジネスモデルキャンバス（新規事業向け）

9つのブロックで事業モデルを可視化する：

1. **顧客セグメント** — 誰に価値を届けるか
2. **価値提案** — 顧客のどんな課題を解決するか
3. **チャネル** — どうやって届けるか
4. **顧客との関係** — どう維持するか
5. **収益の流れ** — どうやって稼ぐか
6. **主要リソース** — 何が必要か
7. **主要活動** — 何をするか
8. **主要パートナー** — 誰と組むか
9. **コスト構造** — いくらかかるか

## ワークフロー

### Step 1: ヒアリング
- 分析対象の事業・製品を特定
- 経営者が特に気にしている点を確認
- 利用可能なデータ・情報を確認

### Step 2: フレームワーク選択
| 状況 | 推奨フレームワーク |
|------|------------------|
| 自社の立ち位置を整理したい | SWOT |
| 競合との差別化を考えたい | 3C |
| 外部環境の変化を把握したい | PEST |
| 新規事業を検討したい | ビジネスモデルキャンバス |
| 総合的な事業計画を作りたい | 全て組み合わせ |

### Step 3: 分析実行
- 各フレームワークのテンプレートに沿って情報を整理
- 推測ではなく事実・データを基にする（ない場合はその旨明記）

### Step 4: 戦略提案
- 分析結果から導かれる戦略オプションを3つ程度提示
- 各オプションのメリット・デメリット・実現性を比較
- 推奨戦略とその根拠を明示

## 注意事項
- 「分析のための分析」にならないよう、必ずアクションに繋げる
- 競合情報は公開情報ベースで。推測は推測と明記する
- 数字が出せる場合はざっくりでも出す（TAM/SAM/SOM等）
