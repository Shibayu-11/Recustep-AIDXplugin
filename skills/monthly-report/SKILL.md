# 月次経営レポート自動生成スキル

## いつ使うか

- 毎月の経営レポート作成時（定期実行推奨）
- 「今月のレポート作って」と言われたとき
- data/financial/ に新しいExcelが置かれたとき

## ワークフロー

### Phase 1: データ取得

1. `data/financial/` 内の最新Excelファイルを検出
2. 前月・前年同月のデータも取得（比較用）
3. ファイルがない場合はエラーではなく「データを配置してください」と案内

### Phase 2: 分析実行

以下を自動算出：

#### 売上分析
- 月次売上高（前月比、前年比）
- セグメント別売上（あれば）
- 売上トレンド（直近6ヶ月の推移）

#### 利益分析
- 粗利益率、営業利益率
- 前月比・前年比の変動要因
- 販管費の主要増減項目

#### キャッシュフロー
- 月末キャッシュポジション
- 売掛金回転日数
- 買掛金回転日数
- 今後3ヶ月の資金繰り見通し

#### KPIサマリー
- 主要KPI 5-7個を予算vs実績で比較
- 達成率とトレンド矢印（↑→↓）

### Phase 3: レポート生成

`templates/report.html` を使ってHTML出力。

```python
context = {
    "title": "2026年3月度 月次経営レポート",
    "date": "2026/04/11",
    "report_title": "月次経営レポート",
    "summary": "売上高は前月比+12%と好調...",
    "kpis": [...],
    "analysis": "...",
    "actions": [...],
    "notes": "...",
}
```

### Phase 4: GBrainに記録

- `analyses/monthly-YYYYMM.md` にレポート要約を保存
- 前月との差分をタイムラインに追記
- 異常値があれば関連エージェントへのアラートを記録

## レポート構成

```markdown
## 2026年3月度 月次経営レポート

### エグゼクティブサマリー
[3行以内で今月の結論。良いニュース→悪いニュース→アクションの順]

### KPIダッシュボード
| 指標 | 実績 | 予算 | 達成率 | 前月比 | 評価 |
|------|------|------|--------|--------|------|
| 売上高 | 5,200万 | 5,000万 | 104% | +12% | PASS: |
| 営業利益率 | 15.2% | 14.0% | 109% | +1.2pt | PASS: |
| ... | ... | ... | ... | ... | ... |

### 売上分析
[セグメント別の増減要因]

### 費用分析
[主要な増減項目とその理由]

### キャッシュフロー
[月末残高、売掛回転、今後の見通し]

### WARNING: 注意事項
[放置するとリスクになる項目]

### PASS: 推奨アクション
1. [今週やること]
2. [今月やること]
3. [来月に向けて]
```

## 定期実行の設定

毎月第5営業日に自動実行を推奨：

```
社長 > 月次レポート作って
```

または、クライアント導入時にリマインダーを設定：
- 毎月5日に「data/financial/ に先月のデータを置いてください」と案内
- データが置かれたら自動でレポート生成

## このスキルが解約防止になる理由

- 毎月の定期接点が生まれる
- 経営者が「AIDXがないと不安」になる
- レポートの品質が月を追うごとに向上（GBrainが過去データを蓄積）
- 数ヶ月分のトレンドが見えるようになると手放せなくなる
