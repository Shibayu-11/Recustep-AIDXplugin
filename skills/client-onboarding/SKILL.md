# クライアントオンボーディングスキル

## いつ使うか

- 新規クライアントとの契約が決まったとき
- Recustepとしてセットアップ代行を行うとき

## 標準オンボーディングフロー（全6ステップ・目標2時間）

### Step 1: ヒアリング（30分）

executive-briefingスキルを使用。以下を必ず収集：

**必須情報:**
- [ ] 会社名、業種、従業員数、年商
- [ ] 代表者名、担当者名、連絡先
- [ ] 主要な経営課題（3つまで絞る）
- [ ] 現在使っているツール（会計ソフト、チャット、グループウェア等）
- [ ] セキュリティ要件（社内規程の有無、情報管理の方針）

**任意情報:**
- [ ] 決算月
- [ ] 主要取引先
- [ ] 過去のAIツール利用経験
- [ ] 補助金の利用経験

### Step 2: 環境セットアップ（30分）

クライアントPCに以下をセットアップ：

```bash
# 1. リポジトリクローン
git clone https://github.com/Shibayu-11/Recustep-AIDXplugin.git
cd Recustep-AIDXplugin

# 2. Python依存パッケージ
pip install -r requirements.txt

# 3. APIキー設定
cp .env.example .env
# → クライアントのAnthropicキーを記入

# 4. 動作確認
python main.py "テスト: こんにちは"

# 5. GBrain（オプション・推奨）
# Docker + ローカルPostgresのセットアップ
# → docs/ja-JP/GBRAIN-SETUP.md に従う

# 6. MCP連携（オプション）
# → docs/ja-JP/MCP-SETUP.md に従う
```

### Step 3: カスタマイズ（20分）

クライアント固有の設定：

1. **CLAUDE.mdの業種カスタマイズ**
   - 業界用語の追加
   - 業界特有のKPI基準
   - 競合企業名の登録

2. **GBrainの初期データ投入**
   - `brain/clients/` にクライアント自身のページを作成
   - `brain/org/` に経営方針・社内規程を記録
   - `brain/companies/` に主要取引先を登録

### Step 4: 初期分析（20分）

クライアントが持っているデータで即座に価値を出す：

1. **財務データがある場合**: `data/financial/` に配置→月次レポート生成
2. **契約書がある場合**: `data/contracts/` に配置→リスクチェック実行
3. **どちらもない場合**: 補助金診断を実行（データ不要で価値が出る）

> **鉄則: 初日に1つは成果物を渡す。**
> 「すごい、これが欲しかった」を初日に言わせる。

### Step 5: トレーニング（15分）

クライアントに以下を実演：

1. `python main.py` で起動
2. 「今月の売上を分析して」→ 財務エージェントが動くのを見せる
3. 「この契約書をチェックして」→ 法務エージェントが動くのを見せる
4. 「議事録を作って」→ 秘書エージェントが動くのを見せる
5. 「終了」で終了

伝えること：
- 日本語で話しかけるだけでOK
- data/ にファイルを置くだけで分析できる
- 困ったらまたRecustepに連絡
