# 契約書 深層レビュースキル

## いつ使うか

- 金額が大きい契約（年間500万円以上）
- 長期契約（1年以上）
- 新規取引先との初めての契約
- 「この契約、本当に結んでいいのか？」と迷っているとき
- 相手方から修正案が来て、受け入れるべきか判断に迷うとき

## 通常レビューとの違い

| | 通常レビュー | 深層レビュー |
|---|---|---|
| 目的 | 条項ごとのリスク判定 | 契約全体の「結ぶべきか」の判断 |
| 出力 | HIGH/MEDIUM/LOW | 金額換算されたリスク + 交渉戦略 |
| 深さ | 7条項チェック | 立場分析 + シナリオ分析 + 交渉優先度 |

## ワークフロー

### Phase 1: 立場の整理

まず冷静になるために、双方の立場を構造化する。

```markdown
## 立場の整理

### 自社の状況
- この取引がなくなった場合の影響: [致命的 / 痛いが代替あり / 軽微]
- 他の選択肢: [競合他社への乗り換え可能か？]
- 時間的プレッシャー: [急いでいるか？]
- この取引への依存度: [売上の何%を占めるか]

### 相手方の状況
- 相手にとっての代替: [自社以外の選択肢はあるか？]
- 相手の急ぎ度: [相手は急いでいるか？]
- 力関係: [自社が強い / 対等 / 相手が強い]

### 感情チェック
- 「早く決めたい」という焦りはないか？ → 焦りは不利な条件を飲む最大の原因
- 「相手に悪い」という遠慮はないか？ → ビジネスの交渉に遠慮は不要
- 「これを逃したら」という恐怖はないか？ → 本当に唯一の選択肢か？
```

この整理を最初に出すこと。経営者が冷静に判断できる土台を作る。

### Phase 2: リスクの金額換算

条項ごとのリスクを「最悪いくら損するか」で数値化する。

```markdown
## リスクの金額換算

| 条項 | リスク | 最悪のシナリオ | 想定損害額 | 発生確率 |
|------|--------|-------------|----------|---------|
| 損害賠償（上限なし） | HIGH | 納品物に不具合→全額賠償請求 | 最大○○万円 | 低（5%） |
| 自動更新（解約予告6ヶ月） | MEDIUM | 解約忘れで1年延長 | ○○万円/年 | 中（20%） |
| 知財帰属（相手方） | HIGH | 自社の技術が使えなくなる | 算定困難 | 低（3%） |
| 支払サイト（60日→90日） | MEDIUM | 資金繰り悪化 | 金利負担○万円 | 高（80%） |

### リスク総額（最悪ケース合計）: ○○万円
### 期待損失額（確率加重）: ○○万円
### 契約金額に対するリスク比率: ○○%
```

**金額が見えると判断できる。** 「HIGH」だけでは経営者は動けない。

### Phase 3: 3つのシナリオ分析

```markdown
## シナリオ分析

### ベストケース（全てうまくいく）
- 売上: +○○万円/年
- 利益率: ○○%
- 取引関係: 長期安定

### 通常ケース（普通に進む）
- 売上: +○○万円/年
- リスク顕在化: 支払サイト90日による金利負担○万円
- 純利益: ○○万円

### ワーストケース（最悪の事態）
- 損害賠償請求: ○○万円
- 契約解除不能期間: ○ヶ月
- 対応コスト（弁護士費用等）: ○○万円
- 最悪の場合の損失合計: ○○万円

### 判断基準
通常ケースの利益 vs ワーストケースの損失 = ○○ : ○○
→ リスクリワード比が○倍 → [受け入れ可能 / 条件修正が必要 / 見送り推奨]
```

### Phase 4: 交渉戦略

```markdown
## 交渉すべき条項（優先度順）

### 絶対に勝ち取るべき（テーブルを立つ覚悟で）
1. **損害賠償上限の設定**
   - 現状: 上限なし（無限責任）
   - 要求: 契約金額を上限
   - 交渉話法: 「双方にとって予見可能なリスクの範囲に限定しましょう」
   - 相手が拒否したら: 保険加入を条件に妥協。それも拒否なら契約見送り

### 強く交渉すべき
2. **支払サイトの短縮**
   - 現状: 月末締め翌々月末（90日）
   - 要求: 月末締め翌月末（60日）
   - 交渉話法: 「下請法の精神に沿って、60日以内でお願いしたい」
   - 妥協点: 翌月末は厳しいなら「翌月20日」

### できれば修正したい
3. **自動更新の予告期間**
   - 現状: 6ヶ月前までに通知がなければ自動更新
   - 要求: 3ヶ月前
   - 交渉話法: 「6ヶ月前だと事業計画の見直し前なので判断が困難」

### 受け入れてよい
- ○○条項: リスクは低く、相手の譲歩ポイントとして使える
```

### Phase 5: 冷静な判断のためのチェックリスト

```markdown
## 契約締結 最終判断チェック

### ビジネス面
- [ ] この取引の売上/利益は目標に合っているか
- [ ] 他に同等以上の選択肢を検討したか
- [ ] 3年後もこの取引関係を維持したいか

### リスク面
- [ ] 最悪のシナリオを想定し、耐えられる範囲か
- [ ] 損害賠償の上限は設定されているか
- [ ] 解約条件は現実的か（ロックイン期間が長すぎないか）

### 感情面
- [ ] 「早く決めたい」という焦りで判断していないか
- [ ] 相手への遠慮で不利な条件を飲んでいないか
- [ ] 他の案件と比較して冷静に判断できているか

### 法務面
- [ ] 弁護士に確認すべき事項を全てリストアップしたか
- [ ] 印紙税の確認は済んだか
- [ ] 反社チェックは完了しているか

### 判定
全てにチェックが入れば → 締結GO
1つでも引っかかれば → 該当箇所を解決してから再判定
```

### Phase 6: GBrainに記録

- `contracts/[相手方名]-review-YYYYMMDD.md` にレビュー結果を保存
- クライアントページに契約状況をタイムラインとして追記
- 契約管理台帳に登録

## このスキルの価値

「契約書のリスクを教えて」で終わるのがsearch-review。
「この契約、結んでいいのか？いくらのリスクを取ることになるのか？どう交渉すべきか？冷静に判断できているか？」まで出すのがdeep-review。

**月7万円の顧問料の価値はここに出る。**

## 注意事項

- 本分析は判断材料の提供であり、法的助言ではありません
- 金額の試算は概算です。正確な損害額の算定は弁護士に依頼してください
- 重要な契約は必ず弁護士の最終確認を受けてください
