# エグゼクティブ・ブリーフィング

## いつ使うか

- 経営者が「相談したい」「どうすればいい？」と漠然とした質問をしたとき
- 新規クライアントとの初回ヒアリング
- 四半期の振り返り・方向性の確認

## 原則

### 曖昧さを許さない
```
× 「売上を伸ばしたいです」
→ 「どの商品の、どのセグメントの売上を、いつまでに、いくら伸ばしたいですか？」

× 「DXを推進したい」
→ 「具体的にどの業務の、何が課題で、どうなれば成功ですか？」
```

### 願望と事実を分ける
- **Interest（関心）**: 「AIを導入したい」→ まだ検討段階
- **Demand（実需）**: 「月40時間の経理作業を半分にしたい」→ 具体的な課題がある

### 直球で返す
```
× 「検討の余地があるかもしれません」
○ 「御社の売掛金回収が62日。業界平均は45日。年間キャッシュフローに1,200万円の差が出ています」
```

## ワークフロー

### Phase 1: コンテキスト収集（5分）

以下を必ず確認する：

1. **会社の基本情報**: 業種、従業員数、売上規模、創業年数
2. **今日の相談テーマ**: 何を解決したいか
3. **緊急度**: 今週中に必要？来月まで？来期に向けて？
4. **過去の取り組み**: これまでに何を試したか
5. **意思決定者**: 最終的に誰が判断するか

### Phase 2: 課題の構造化（10分）

収集した情報を以下のフレームで整理：

```
■ 表面的な課題（経営者が言っていること）
→ [そのまま記録]

■ 根本的な課題（データが示していること）
→ [数字で裏付け]

■ 本当に解決すべきこと
→ [表面と根本のギャップから導出]
```

### Phase 3: 診断結果の提示

```markdown
## 診断結果

### 御社の状態
[1-2文で現状を端的に表現。数字を使う]

### 3つの課題（優先度順）
1. **[最重要]** — [根拠となる数字] → [放置した場合のリスク]
2. **[重要]** — [根拠] → [リスク]
3. **[注意]** — [根拠] → [リスク]

### 推奨アクション（今すぐ → 今月 → 来期）
| 時期 | アクション | 期待効果 | 担当 |
|------|-----------|---------|------|
| 今週 | [具体的に] | [数字で] | [誰が] |
| 今月 | [具体的に] | [数字で] | [誰が] |
| 来期 | [具体的に] | [数字で] | [誰が] |

### AIDXでできること
[上記アクションのうち、AIDXエージェントが支援できるもの]
```

### Phase 4: GBrainに記録

- クライアントページを作成/更新（`clients/`）
- 課題と推奨アクションをタイムラインに追記
- 次回フォローアップ事項を記録

## アンチパターン

- 「いろいろ課題がありますね」→ 具体的に3つに絞れ
- 「一般的には〜」→ 御社の数字で話せ
- 「まずは検討しましょう」→ 今すぐできる最小アクションを1つ出せ
- 長い前置き → 結論から言え
