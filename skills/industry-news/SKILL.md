# 業界ニュース自動要約スキル

## いつ使うか

- 「業界の最新ニュース教えて」→ 即時収集・要約
- 「今週の業界動向まとめて」→ 週次レポート生成
- 「競合が何やってるか調べて」→ 競合の最新動向
- 毎週月曜の定期実行（推奨）→ 経営者の朝一の情報源に

## ワークフロー

### Step 1: 業界・キーワードの設定

初回のみ。クライアントの業界に合わせてウォッチ対象を定義する。

```json
// data/news_config.json に保存
{
  "industry": "製造業",
  "company_name": "株式会社サンプル",
  "competitors": ["競合A社", "競合B社", "競合C社"],
  "keywords": ["精密部品", "自動化", "EV", "脱炭素"],
  "negative_watch": ["リコール", "不正", "事故", "訴訟"],
  "rss_feeds": [
    "https://news.google.com/rss/search?q=製造業+DX&hl=ja",
    "https://news.google.com/rss/search?q=精密部品&hl=ja"
  ],
  "frequency": "weekly"
}
```

設定がなければ、経営者に業種と競合を聞いてから実行する。

### Step 2: 情報収集

以下のソースから並列で収集する（Agent Reach連携）:

#### 2-1. Web検索（メイン）
```bash
# Jina Reader経由で検索
curl -s "https://r.jina.ai/https://news.google.com/search?q=キーワード&hl=ja"
```

検索クエリ例:
- `{業界} 最新ニュース 今週`
- `{競合A社} ニュース`
- `{キーワード} トレンド 2026`

#### 2-2. RSS（設定済みの場合）
```bash
# RSSフィードを取得
curl -s "RSSフィードURL" | head -200
```

#### 2-3. Twitter/X（Agent Reach設定済みの場合）
```bash
twitter search "{業界} {キーワード}" --limit 20
```

#### 2-4. YouTube（関連動画）
```bash
yt-dlp "ytsearch3:{業界} 最新動向 2026" --get-title --get-id
```

### Step 3: フィルタリング・分類

収集した情報を以下のカテゴリに分類:

| カテゴリ | 内容 | 重要度 |
|---------|------|--------|
| 自社に直接影響 | 法規制変更、取引先の動向 | 最高 |
| 競合の動き | 新製品、価格変更、提携 | 高 |
| 業界トレンド | 技術革新、市場変化 | 中 |
| マクロ環境 | 経済、政策、社会変化 | 低〜中 |
| ネガティブウォッチ | 業界の事故、不正、リコール | 注意 |

### Step 4: レポート生成

```markdown
## 業界ニュースレポート
**期間:** YYYY/MM/DD 〜 YYYY/MM/DD
**業界:** {業界}

---

### 今週の3行サマリー
1. [最も重要なニュースを1文で]
2. [2番目に重要なニュースを1文で]
3. [3番目に重要なニュースを1文で]

---

### 自社に直接影響するニュース

#### [ニュースタイトル]
- **概要:** [2-3文で要約]
- **御社への影響:** [具体的にどう影響するか]
- **推奨アクション:** [何をすべきか]
- **ソース:** [URL]

---

### 競合の動き

#### {競合A社}
- [動向の要約]
- **示唆:** [御社にとっての意味]

#### {競合B社}
- [動向の要約]

---

### 業界トレンド

| トレンド | 概要 | 御社との関連性 |
|---------|------|-------------|
| [テーマ] | [要約] | [高/中/低] |
| [テーマ] | [要約] | [高/中/低] |

---

### 注意情報

- [ネガティブウォッチに引っかかったもの]

---

### 来週の注目ポイント
1. [来週注目すべきイベント・発表]
2. [フォローすべき動向]
```

### Step 5: 保存・蓄積

- レポートを `data/news_report_YYYYMMDD.md` に保存
- GBrainが接続されていれば `analyses/industry-news-YYYYMMDD.md` にも保存
- 競合ページに新しい動向をタイムラインとして追記

## 定期実行の設定

毎週月曜の朝にClaude Codeで:

```
> 今週の業界ニュースまとめて
```

または朝のブリーフィングに組み込む:

```
> 今日のブリーフィング
→ [タスク・リマインダー]
→ [今週の業界ニュース3行サマリー]  ← 自動で含まれる
```

## 初回セットアップ

クライアント導入時に以下を確認:

1. 業種は何か
2. 競合は誰か（3社まで）
3. ウォッチしたいキーワード（5個まで）
4. ネガティブウォッチワード（リコール、不正等）

これを `data/news_config.json` に保存すれば、以降は自動で収集。

## 注意事項

- Webから収集した情報の正確性は保証されない。重要な判断は一次ソースを確認
- 有料記事は全文が取れない場合がある（見出し+冒頭のみ）
- RSSフィードが無効になっている場合はWeb検索にフォールバック
- 収集頻度が高すぎるとAPI制限に引っかかる可能性あり（週1回推奨）
