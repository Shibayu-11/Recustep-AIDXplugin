# 事業承継チェックスキル

## いつ使うか

- 経営者が60歳以上で後継者問題の話題が出たとき
- 「会社を誰かに継がせたい」「M&Aも考えている」と言われたとき
- 事業承継税制の活用を検討するとき

## 背景

- 日本の中小企業経営者の平均年齢は **62.5歳**（2025年時点）
- 後継者不在率は **約60%**
- 事業承継の準備開始から完了まで平均 **5〜10年**
- 早期の準備が税制優遇・円滑な引継ぎの鍵

## 3つの承継パターン

| パターン | 概要 | メリット | リスク |
|---------|------|---------|--------|
| **親族内承継** | 子・親族に引き継ぐ | 従業員・取引先の理解を得やすい | 後継者の経営能力、相続税・贈与税 |
| **従業員承継（MBO）** | 役員・従業員に引き継ぐ | 事業理解が深い | 株式取得資金の調達、個人保証の問題 |
| **第三者承継（M&A）** | 外部の会社・個人に売却 | 後継者不在でも事業継続可能 | 企業文化の変化、従業員の不安 |

## ワークフロー

### Phase 1: 現状診断

以下を確認：

1. **経営者情報**: 年齢、健康状態、引退希望時期
2. **後継候補**: 親族・従業員・外部の候補者の有無
3. **株式構成**: 経営者の持株比率、他の株主
4. **自社株評価**: 概算の株価（純資産方式/類似業種比準方式）
5. **個人保証**: 銀行借入の連帯保証の有無
6. **知的資産**: 属人的なノウハウ・顧客関係の整理状況

### Phase 2: 課題の構造化

```markdown

### 基本情報
| 項目 | 状態 |
|------|------|
| 経営者年齢 | [X歳] |
| 引退希望 | [時期] |
| 後継候補 | [有/無/検討中] |
| 承継パターン | [親族/従業員/M&A/未定] |

### 🟡 準備が必要な課題

```

### Phase 3: 準備計画の策定

```markdown
### 事業承継ロードマップ（目安）

| 時期 | やること | 担当 |
|------|---------|------|
| 即座 | 自社株評価の概算を確認 | AIDX財務エージェント |
| 3ヶ月以内 | 後継候補との対話開始 | 経営者 |
| 6ヶ月以内 | 顧問税理士と承継税制の相談 | 経営者 + 税理士 |
| 1年以内 | 承継計画書の策定 | 経営者 + AIDX |
| 2〜3年 | 後継者への権限移譲（段階的） | 経営者 + 後継者 |
| 3〜5年 | 株式移転・代表交代 | 経営者 + 専門家 |
```

### Phase 4: 専門家連携の提案

事業承継は専門家の関与が必須：
- **顧問税理士**: 自社株評価、承継税制の適用
- **弁護士**: 株式譲渡契約、遺言書
- **M&Aアドバイザー**: 第三者承継の場合
- **事業承継・引継ぎ支援センター**: 公的な無料相談窓口（全国47箇所）

## 事業承継税制のポイント

- **特例措置**: 一定の要件を満たせば贈与税・相続税の納税猶予（実質免除）
- **要件**: 都道府県知事の認定、承継計画の提出、雇用維持要件等
- **期限**: 特例措置には申請期限があるため早めの対応が必要

> AIDXは税務アドバイスを行いません。税制の詳細は必ず税理士に確認してください。
