# 日本語ビジネス文書作法

## 基本方針

AIDXエージェントが生成する全ての日本語文書は、**日本のビジネス慣習に沿ったプロフェッショナルな品質**を維持すること。

## 敬語・文体

### 社外向け文書（提案書、メール、報告書）
- 「です・ます」調を基本とする
- 尊敬語・謙譲語を正しく使い分ける
- 二重敬語を避ける（× ご覧になられる → ○ ご覧になる）
- クッション言葉を適切に使う（「恐れ入りますが」「お手数ですが」）

### 社内向け文書（議事録、社内メモ）
- 「です・ます」調または「だ・である」調を統一して使う
- 同一文書内で文体を混在させない

### 経営者への報告
- 結論を先に述べる（結論 → 理由 → 詳細）
- 数字は具体的に（× 大幅に増加 → ○ 前月比+12%増加）
- 専門用語は避けるか、初出時に説明を添える

## 数値表記

| 種類 | 表記例 | ルール |
|------|--------|--------|
| 金額 | 5,200万円 | 3桁カンマ区切り、万円/億円単位を使う |
| 割合 | 15.2% | 小数点以下1桁まで |
| 前年比 | 前月比+12% | 増減記号を必ず付ける |
| 日付 | 2026年4月11日 / 2026/04/11 | 和暦は使わない（令和は不要） |
| 期間 | 2026年4月〜6月 | 全角チルダ使用 |

## 文書構成

### 報告書・レポート
1. タイトル
2. エグゼクティブサマリー（1-3文で結論）
3. 本文（分析・詳細）
4. 推奨アクション
5. 補足・注記

### 提案書
1. タイトル・宛先
2. エグゼクティブサマリー
3. 背景・課題
4. 提案内容
5. 期待効果
6. スケジュール・予算
7. リスクと対策

### 議事録
1. 基本情報（日時、場所、参加者、議題）
2. 決定事項
3. アクションアイテム（担当・期限付き）
4. 議論の要点
5. 次回予定

### ビジネスメール
1. 件名（20文字以内、用件が分かるように）
2. 宛名（○○株式会社 ○○様）
3. 挨拶（「お世話になっております」等）
4. 本文（結論→理由→詳細→依頼事項）
5. 結び（「ご確認のほどよろしくお願いいたします」等）
6. 署名

## 禁止事項

- 英語の直訳調（× それは良いアイデアです → ○ ご提案の方向で進めましょう）
- 曖昧な表現の多用（× いろいろ → ○ 具体的に列挙する）
- 主語の省略が不明確になるケース（経営者が「誰が」を即座に理解できること）
- 半角カタカナの使用
- 機種依存文字の使用（①②③ → 1. 2. 3.）
