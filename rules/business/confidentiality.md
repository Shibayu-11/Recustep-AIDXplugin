# 機密情報取扱規定

## 絶対遵守事項

1. **APIキーをGitにコミットしない** — `.env` で管理、`.gitignore` に記載済み
2. **`data/` ディレクトリの内容をGitにコミットしない** — 財務・契約・人事データは全て機密
3. **機密データをログに出力しない** — デバッグ時も個人情報・財務数値はマスクする
4. **外部APIへの送信は最小限** — Claude API呼び出し時もデータ本体ではなく要約を送信

## データ分類

| 分類 | 例 | 取り扱い |
|------|-----|---------|
| **極秘** | 未公開財務データ、M&A情報、給与明細 | ローカルのみ。API送信禁止 |
| **社外秘** | 契約書、事業計画、顧客リスト | ローカル処理優先。API送信時は要約化 |
| **社内限定** | 議事録、社内規程、組織図 | ローカル処理。必要最小限のAPI利用可 |
| **公開可** | 会社概要、採用情報、プレスリリース | 制限なし |

## Claude API利用時の注意

- Anthropicの利用規約に基づき、APIに送信されたデータはモデルの学習には使用されない
- ただし、機密度の高いデータは極力ローカルで処理し、APIには質問・指示のみを送信すること
- 契約書の全文送信は避け、該当条項のみを抜粋して送信する
- 財務データは集計値・比率のみを送信し、個別取引データは送信しない

## ファイル管理

- `data/financial/` — 財務データ専用。Excel/CSVを配置
- `data/contracts/` — 契約書PDF専用
- `data/knowledge/` — 社内ナレッジ・マニュアル等
- 上記は全て `.gitignore` でGit管理対象外
- バックアップは社内ファイルサーバーまたは暗号化クラウドストレージで行うこと

## インシデント対応

万が一、機密データが外部に漏洩した場合：
1. 即座にAPIキーをローテーション（Anthropicコンソールで再発行）
2. 漏洩範囲の特定と記録
3. 影響を受ける関係者への通知
4. 再発防止策の策定と実施
