# HTML出力品質基準

## 基本方針

AIDXエージェントが生成する全てのドキュメントは、**そのまま印刷・PDF化して顧客に提出できる品質**を維持すること。

## デザイン規定

- **ベーステンプレート**: `templates/base.html` を必ず継承する
- **カラー**: 黒背景（#111）ヘッダー/フッター、ライムグリーン（#c8ff00）アクセント、ベージュ（#f7f5f0）本文背景
- **フォント**: Noto Sans JP（本文）、Bebas Neue（見出し）、Space Mono（データ・ラベル）
- **レスポンシブ**: モバイルでも崩れない（700px以下でグリッド変更）
- **印刷対応**: `@media print` でヘッダー・フッターの改ページ制御

## テンプレート使い分け

| 用途 | テンプレート | 使用エージェント |
|------|-------------|-----------------|
| 財務レポート | `report.html` | 財務エージェント |
| 提案書 | `proposal.html` | 秘書・戦略エージェント |
| 議事録 | `minutes.html` | 秘書エージェント |
| 契約書チェック | `contract-check.html` | 法務エージェント |

## 品質チェックリスト

- [ ] 日付が正しく記載されている
- [ ] 会社名・宛名に誤りがない
- [ ] 数値に単位が付いている（円、%、倍など）
- [ ] 表の列見出しが明確
- [ ] 免責事項が必要な場合は記載されている（法務・労務）
- [ ] フッターに「CONFIDENTIAL」が表示されている

## Markdown出力時のルール

HTML出力が不要な場合（チャット返信、社内メモ等）はMarkdownで出力する。

- 見出しは `##` から開始（`#` はタイトルのみ）
- 箇条書きは `-` を使用
- 表は必ずヘッダー行を含める
- コードブロックは使用しない（経営者向けドキュメントにコードは不要）
