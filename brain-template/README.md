# AIDX Brain — 社内ナレッジベース

このディレクトリはGBrainのナレッジリポジトリのテンプレートです。
各ディレクトリにMarkdownファイルを配置することで、エージェントが自動的にナレッジを蓄積・検索・活用します。

## ディレクトリ構成

```
brain/
├── clients/      ← 顧客・取引先（1社1ファイル）
├── companies/    ← 競合・パートナー企業
├── meetings/     ← 会議記録・議事録
├── analyses/     ← 財務分析・市場分析の結果
├── contracts/    ← 契約レビューの要約・結論
├── employees/    ← 社員情報・評価記録
├── projects/     ← 進行中のプロジェクト
├── org/          ← 経営方針・社内規程・戦略
├── inbox/        ← 未整理の情報（一時置き場）
└── README.md     ← このファイル
```

## ページの書き方

GBrainの「二層構造」に従います：

### 上半分：コンパイルされた真実（最新の状態）
新しい情報が入ったら上書き更新する。常に「今の正確な状態」を反映。

### 下半分：タイムライン（追記のみ）
時系列で事実を記録。絶対に編集・削除しない。証拠の積み重ね。
