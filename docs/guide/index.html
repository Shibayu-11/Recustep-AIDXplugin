AIDXの使い方ガイド

クローンして、起動して、話しかける。
それだけで5人のAI部下が動き出します。

Setup

セットアップは2ステップ

Claude Max プラン（$200/月・使い放題）に加入していれば、すぐ始められます。

1

リポジトリをダウンロード

ターミナルを開いて以下をコピー&ペースト

TERMINAL
git clone https://github.com/Shibayu-11/Recustep-AIDXplugin.git cd Recustep-AIDXplugin
2

Claude Codeを起動

同じターミナルでこれだけ

TERMINAL
claude

初回はAnthropicアカウントでログインを求められます。完了すれば即座にAI部下が稼働します。

i

Claude Codeが入ってない場合: npm install -g @anthropic-ai/claude-code で先にインストールしてください。Node.jsが必要です。

Usage

日本語で話しかけるだけ

特別なコマンドは不要。普通の日本語で指示すれば、最適なAI部下が自動で対応します。

CLAUDE CODE
# 財務分析 > 今月の売上を分析して # 契約書チェック > data/contracts/業務委託契約書.pdf のリスクを教えて # 議事録作成 > 今日の会議の議事録を作って。参加者は田中、佐藤、鈴木。 # 戦略分析 > うちの会社のSWOT分析をして # 補助金診断 > うちが使える補助金ある？製造業、従業員50人 # 見積書作成 > A社向けにコンサル費用の見積書を作って

データを分析させるには

1

ファイルを置く

Excelは data/financial/ に、契約書PDFは data/contracts/ にドラッグ&ドロップ

2

話しかける

「data/financial/売上表.xlsx を分析して」と入力するだけ

3

結果を受け取る

AIが自動でグラフ・表・推奨アクション付きのレポートを生成します

Folders

触っていいのは3つだけ

フォルダがたくさんありますが、あなたが使うのはこれだけ。他は全部システムが使います。

F

財務データ

data/financial/

Excel、CSVを置くだけ。置いたら「分析して」と言うだけ。

C

契約書

data/contracts/

契約書PDFを置くだけ。「チェックして」でリスク分析が走る。

K

社内資料

data/knowledge/

マニュアル、規程、ルールを置くとAIが記憶して活用する。

上記以外のフォルダは触らないでください。 aidx_agents/、tools/、templates/、skills/ 等はシステム内部です。 変更するとAIが正常に動かなくなる可能性があります。 設定変更が必要な場合はRecustepにご相談ください。

FAQ

よくある質問

claude コマンドが見つからない
npm install -g @anthropic-ai/claude-code を実行してください。Node.jsが未インストールの場合は先にNode.jsを入れてください。
ログインできない
Anthropicアカウントが Max プラン（$100 or $200）であることを確認してください。無料プランではClaude Codeは使えません。
応答が遅い / エラーが出る
Anthropicのサービス状況（status.anthropic.com）を確認してください。一時的な障害の場合があります。
Windowsで動く？
はい。PowerShellから同じ手順で使えます。パスに日本語が含まれるとエラーになる場合があるので、英数字のみのフォルダに配置してください。
データは外部に送信される？
質問文のみがClaude AIに送信されます。Excel、PDF等の生データは送信されず、ローカルで処理されます。APIキーや機密データがGitにコミットされることもありません。
月額料金は？
Claude Max プラン $200/月（約3万円）のみ。使い放題で従量課金の心配はありません。Recustepの導入サポートは別途月額7万円です。
何か壊れた / 設定を変えたい
Recustepの担当者にご連絡ください。CLAUDE.mdの変更で対応します。ご自身でシステムフォルダを編集しないでください。
