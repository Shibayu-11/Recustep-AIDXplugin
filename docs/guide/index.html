Overview

やることは全部で5つ

上から順番にやってください。全部で30分〜1時間で終わります。

1. Anthropic（AI会社）のアカウントを作る
2. VS Code（エディタ）をインストールする
3. Claude Code（AIツール）をインストールする
4. AIDXをダウンロードする
5. 起動して話しかける

Recustepがセットアップ代行する場合: この手順はRecustepの担当者が全てやります。あなたはStep 1（アカウント作成）だけやれば大丈夫です。
Step 1

Anthropicのアカウントを作る

AIDXの頭脳となるAI（Claude）を使うためのアカウントです。

1-1

claude.ai にアクセス

ブラウザ（Chrome、Safari等）で以下を開いてください：

ブラウザのアドレスバーに入力
https://claude.ai/
1-2

アカウントを作成

  1. 「Sign Up」をクリック
  2. メールアドレスを入力（Googleアカウントでもログインできます）
  3. 届いた確認メールのリンクをクリック
1-3

Maxプランに加入

  1. ログイン後、画面の「Upgrade」ボタンをクリック
  2. 「Max」プランを選択（$200/月 — 使い放題）
  3. クレジットカード情報を入力して完了
なぜMaxプラン？ 月額固定で使い放題です。従量課金（使った分だけ請求）と違い、「今月いくらかかるか分からない」という心配がありません。月約3万円で5人のAI部下が使い放題です。
Step 2

VS Codeをインストール

VS Code（ブイエスコード）はMicrosoftが無料で提供しているエディタです。AIDXはこの中で動きます。

2-1

VS Codeをダウンロード

以下のページを開いて、あなたのパソコンに合ったものをダウンロード：

ブラウザで開く
https://code.visualstudio.com/
  • Mac → 「Download for Mac」をクリック
  • Windows → 「Download for Windows」をクリック
2-2

インストール

  • Mac: ダウンロードした .zip を開く → 「Visual Studio Code」をアプリケーションフォルダにドラッグ
  • Windows: ダウンロードした .exe をダブルクリック → 「次へ」を押していくだけ
2-3

VS Codeを開く

アプリケーション一覧から「Visual Studio Code」を開いてください。青いアイコンが目印です。

英語の画面が出ますが、問題ありません。このまま進めます。

Step 3

Claude Codeをインストール

Claude CodeはAIとやり取りするためのツールです。まず、その土台となるNode.jsを入れます。

3-1

Node.jsをインストール

以下のページを開いてダウンロード：

ブラウザで開く
https://nodejs.org/

「LTS」と書かれた緑色のボタンをクリックしてダウンロード。ダウンロードしたファイルをダブルクリックしてインストール（全て「次へ」でOK）。

3-2

ターミナルを開く

ターミナルとは、パソコンに文字で命令を出す画面です。

  • Mac: VS Codeの上メニュー →「Terminal」→「New Terminal」
    または、Macの「アプリケーション」→「ユーティリティ」→「ターミナル」
  • Windows: VS Codeの上メニュー →「Terminal」→「New Terminal」
    または、スタートメニューで「PowerShell」を検索して開く

黒い画面（またはVS Codeの下部パネル）にカーソルが点滅していればOKです。

3-3

Claude Codeをインストール

ターミナルに以下をコピー&ペーストして、Enterキーを押してください：

ターミナルにコピー&ペースト
npm install -g @anthropic-ai/claude-code

数十秒待って、エラーが出なければ完了です。

エラーが出た場合（Mac）: 先頭に sudo を付けて再実行してください：
sudo npm install -g @anthropic-ai/claude-code
パスワードを聞かれたら、Macのログインパスワードを入力（画面には表示されません）。
3-4

Gitをインストール（まだ入ってない場合）

ターミナルで以下を試してください：

ターミナル
git --version

バージョンが表示されればOK。「command not found」と出たら：

  • Mac: ターミナルで xcode-select --install を実行 →「インストール」をクリック
  • Windows: https://git-scm.com/downloads からダウンロードしてインストール
Step 4

AIDXをダウンロード

ターミナルにコマンドを2つ入れるだけです。

4-1

ダウンロード

ターミナルに以下をコピー&ペーストして、Enterキーを押してください：

ターミナルにコピー&ペースト
git clone https://github.com/Shibayu-11/Recustep-AIDXplugin.git cd Recustep-AIDXplugin

数秒でダウンロードが完了します。

4-2

VS Codeでフォルダを開く

VS Codeの上メニュー →「File」→「Open Folder」→ ダウンロードした「Recustep-AIDXplugin」フォルダを選択して「開く」をクリック。

左側にファイル一覧が表示されればOKです。

Step 5

起動する

たった1コマンドです。

5-1

Claude Codeを起動

VS Code内のターミナルに以下を入力してEnter：

ターミナル
claude
5-2

ログイン

初回のみ、ブラウザが開いてAnthropicアカウントでのログインを求められます。

  1. ブラウザでAnthropicにログイン
  2. 「許可」をクリック
  3. ターミナルに戻ると、AIDXが使える状態になっています
5-3

話しかける

ターミナルに > マークが表示されたら準備完了。日本語で何でも聞いてください。

AIDXに話しかける
> 今月の売上を分析して
おめでとうございます！ これでAIDXの5人のAI部下が使えるようになりました。

こう話しかけてください

特別なコマンドは不要。普通の日本語でOKです。

"議事録を作って"

→ タスクに自動登録、期限管理

→ タスク+リマインダー+優先度をまとめて報告

→ 3日後のブリーフィングで通知

"この契約、結んでいいか迷ってる"

データを分析させるには

1. VS Codeの左側で data/financial/ フォルダを見つける
2. そこにExcelファイルをドラッグ&ドロップ
3. ターミナルで「data/financial/売上表.xlsx を分析して」と話しかける

契約書PDFも同じ要領で data/contracts/ に入れるだけです。

終了するには

ターミナル
> /exit

または Ctrl + C を押してください。

Folders

触っていいフォルダは3つだけ

VS Codeの左側にフォルダがたくさん並んでいますが、あなたが使うのはこれだけ。

data/financial/
売上データ（Excel、CSV）を入れる場所。入れたら「分析して」と言うだけ
data/contracts/
契約書（PDF）を入れる場所。入れたら「チェックして」と言うだけ
data/knowledge/
社内マニュアル・規程を入れる場所。AIが記憶して活用します
上記以外のフォルダは触らないでください。 システムの内部ファイルです。変更するとAIDXが正常に動かなくなります。 設定変更が必要な場合はRecustepにご連絡ください。
FAQ

よくある質問

「claude」と入力しても何も起きない
Claude Codeがインストールされていない可能性があります。ターミナルで npm install -g @anthropic-ai/claude-code を実行してください。
「npm」と入力してもエラーが出る
Node.jsがインストールされていません。Step 3-1 に戻って Node.js をインストールしてください。インストール後、ターミナルを一度閉じて開き直してください。
「git」と入力してもエラーが出る
Gitがインストールされていません。Step 3-4 に戻ってインストールしてください。
ログインできない
Anthropicアカウントが Max プランであることを確認してください。無料プランや Pro プランでは Claude Code は使えません。
応答が遅い / エラーが出る
Anthropicのサービス状況（status.anthropic.com）を確認してください。一時的な障害の可能性があります。しばらく待ってから再度お試しください。
Windowsで動く？
はい。上記の手順はMacでもWindowsでも同じです。PowerShellから同じコマンドが使えます。
データは外部に送られる？
質問文のみがAIに送信されます。Excel・PDF等の生データはあなたのパソコンの中で処理され、外部に送信されません。
月額料金は？
Claude Max プラン $200/月（約3万円）のみ。使い放題で追加料金はかかりません。Recustepの導入サポートは別途月額7万円です。
何か壊れた / よく分からない
Recustepの担当者にご連絡ください。リモートで対応いたします。
