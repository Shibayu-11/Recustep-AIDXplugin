フォルダガイド — どこを触っていいか

このプロジェクトにはたくさんのフォルダがありますが、
あなたが触る必要があるのは3つだけです。残りはシステムが自動で使います。

---

あなたが使うフォルダ（触ってOK）

data/ — あなたのデータを置く場所

data/
├── financial/    ← Excelや CSVを置くだけで財務分析が動く
├── contracts/    ← 契約書PDFを置くだけで法務チェックが動く
└── knowledge/    ← 社内マニュアルや規程を置くと記憶に使われる

使い方:ファイルをドラッグ&ドロップで入れるだけ。あとはAIに「分析して」と話しかけてください。

brain/ — AIの記憶（GBrain使用時のみ）

brain/
├── clients/      ← 顧客・取引先の情報が自動で貯まる
├── meetings/     ← 会議記録が自動で保存される
├── analyses/     ← 分析結果が自動で保存される
└── ...           ← AIが自動で管理するので基本触らなくてOK

使い方:GBrainをセットアップすると自動で作られます。中身はAIが管理するので、基本的に触る必要はありません。

.env — APIキーの設定ファイル

ANTHROPIC_API_KEY=sk-ant-あなたのキー

使い方: 最初に一度だけ設定すればOK。

---

見なくていいフォルダ（システム内部）

以下は全てAIDXシステムの内部ファイルです。**触らないでください。**
壊すとシステムが正常に動かなくなる可能性があります。

| フォルダ | 何が入ってるか | 触る？ |
|---------|-------------|--------|
| `aidx_agents/` | AIエージェントのプログラム本体 | 触らない |
| `tools/` | データ処理ツール（Excel読み込み等） | 触らない |
| `templates/` | HTMLレポートのデザイン | 触らない |
| `agents/` | ECC互換エージェント定義 | 触らない |
| `skills/` | AIのスキル定義 | 触らない |
| `rules/` | AIの行動ルール | 触らない |
| `hooks/` | 自動化トリガー | 触らない |
| `commands/` | コマンド定義 | 触らない |
| `scripts/` | 内部スクリプト | 触らない |
| `mcp-configs/` | 外部サービス連携設定 | 触らない |
| `contexts/` | AIのコンテキスト設定 | 触らない |
| `manifests/` | インストール設定 | 触らない |
| `examples/` | 設定サンプル | 触らない |
| `docs/` | ドキュメント（読むのはOK） | 読むだけ |
| `ecc2/` | ECC v2（開発中） | 触らない |
| `.github/` | CI/CD設定 | 触らない |
| `.claude/` | Claude Code設定 | 触らない |

---

ファイルの説明

触ってOK

| ファイル | 説明 |
|---------|------|
| `.env` | APIキー設定（最初に一度だけ） |

読むだけ

| ファイル | 説明 |
|---------|------|
| `README.md` | プロジェクト説明・セットアップ手順 |
| `CLAUDE.md` | AIの行動指針（カスタマイズしたい場合はRecustepに相談） |

触らない（システムファイル）

| ファイル | 説明 |
|---------|------|
| `main.py` | 起動スクリプト |
| `requirements.txt` | Python依存パッケージ |
| `package.json` | Node.js設定 |
| `yarn.lock` | Node.js依存ロック |
| `eslint.config.js` | コード品質設定 |
| `commitlint.config.js` | コミット規約設定 |
| `agent.yaml` | エージェント定義 |
| `install.sh` / `install.ps1` | インストールスクリプト |
| その他の `.md` ファイル | 開発者向けドキュメント |

---

困ったときは

- 「どのフォルダに何を置けばいい？」→ `data/` の中の該当フォルダに置くだけ
- 「何か壊れた」→ Recustepに連絡してください
- 「設定を変えたい」→ Recustepに相談してください。CLAUDE.mdの変更で対応します
